Module sampler 

Source
Expand description

Metric sampling and emission. Modeled on object-cache-srv/src/saturation_monitor.rs: pure emit functions driven by a loop in main.rs, so tests can drive one round without the loop.

imetric!/fmetric! require literal metric names (per-call-site static metadata), so each metric is an explicit call; dynamic strings appear only as property values, interned to 'static (bounded cardinality: command names, latency events, db indices, one instance name).
