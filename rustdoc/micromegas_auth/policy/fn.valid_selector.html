pub fn valid_selector(selector: &str) -> bool
Expand description

A principal selector on either axis of an AudienceGrants entry: * (any authenticated principal), user:<email> (matches AuthContext.email), or group:<g> (matches any raw value in AuthContext.groups). Validated at parse time; resolve/resolve_audience never see an unrecognized shape.
