Best-effort extraction of the claimed OTLP Resource identity from a possibly truncated request body, for logging who sent a request that authentication refused.

Only an allowlist of scalar resource attributes is ever retained, so an unexpected custom attribute (which could hold a secret) cannot reach a log through this module. Values are returned as sent: sanitizing them for a log line is the caller’s job.

claimed_resource_from_prefix
Reads the first Resource of the first ResourceLogs/ResourceMetrics/ResourceSpans of an OTLP export request. prefix may be cut anywhere: attributes complete within it are used. All three signals share the layout request.field1 -> Resource*.field1 -> Resource, so no signal parameter is needed. Returns None when nothing could be extracted.
