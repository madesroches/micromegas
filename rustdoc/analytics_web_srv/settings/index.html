Settings admin API for analytics-web-srv.

Admin-only REST routes over the settings table (migration v12). The registry of known keys and the single validation rule live in micromegas::settings; this module only reads and writes rows and audits every change. The read route is AdminUser-gated directly; the two mutation routes go through SettingsAdminGate, which additionally emits a control-plane audit record on rejection, the same shape as groups.rs.
