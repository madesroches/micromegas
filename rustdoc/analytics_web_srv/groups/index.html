Group admin API for analytics-web-srv.

Mirrors analytics_keys.rs/audience_grants.rs’s shape (GroupsState { pool: Option<PgPool> }, an IntoResponse error enum, AdminUser-gated) over the groups/group_members tables (migration v10, rust/ingestion/src/sql_migration.rs). Every write goes through the AdminUser extractor’s gate, which is caller.is_admin today; delegating group ownership later means widening that one gate, not this module’s routing or handler shapes.
