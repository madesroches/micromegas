pub fn expand_path_prefixes(path: &str, include_root: bool) -> Vec<String>
Expand description

Expands path into itself and all of its ancestors, shortest first (root-to-leaf), e.g. "team/sub" -> ["team", "team/sub"]. When include_root is true, the root (empty path) is prepended, e.g. expand_path_prefixes("team/dashboards", true) -> ["", "team", "team/dashboards"].
