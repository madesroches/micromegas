Shared handling of key:<key_id> selectors for the group-member and audience-grant routes.

Functions§

canonicalize_key_selector
Rewrites any Uuid::parse_str spelling after key: to the canonical selector, since matching is an exact string compare. Anything else is returned unchanged, left for the shape check to reject.
ensure_live_key
For a canonical key: selector, the name of the live (not revoked) analytics key it names, or None when there is no such key. Catches typos and ingestion key ids, which live in the other table. Callers run it only after authorization so the answer is not an existence oracle for callers who could not create the row anyway.
key_not_found_message
The 404 body when a key: selector names no live analytics key.
