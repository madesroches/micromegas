Format → decoder registry for parse_block, mirroring BlockProcessorMap Format → decoder registry for parse_block: turns a block payload of any registered streams.format into generic (type_name, jsonb) objects, one per row, mirroring the existing BlockProcessorMap pattern (block_partition_spec.rs).
