Expand description

A unit within the byte cap is written whole. Otherwise it is rebuilt as the leaves plan_by_source_bytes picks, which replace the unit’s rows in one commit, however coarse those rows were. A unit that is itself one finest-rung bucket has nothing to split, so it is written whole whatever its size.
