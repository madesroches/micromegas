ingestion authentication layer that attributes rejected insert_process callers Authentication layer for the ingestion routes.

Wraps micromegas_auth::axum::authenticate_quiet so a rejected insert_process request, the first call any client makes, or an OTLP export, is logged as one line carrying both the rejection reason and the identity its body claims. The 401 response is identical to the one auth_middleware returns.
