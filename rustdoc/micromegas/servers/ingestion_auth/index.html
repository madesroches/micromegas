ingestion authentication layer that attributes rejected insert_process callers Authentication layer for the ingestion routes.

Wraps micromegas_auth::axum::authenticate so a rejected insert_process request, the first call any client makes, can have the process identity it claims logged next to the caller’s network details. The 401 response is identical to the one auth_middleware returns.
