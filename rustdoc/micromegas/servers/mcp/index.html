Module mcp 

Source
Expand description

MCP server exposing guarded query tools to agents MCP (Model Context Protocol) server over Streamable HTTP, for agents that cannot run the micromegas-query CLI.

The module holds the tool logic, guardrails and rendering and knows nothing about the host application. The host validates the bearer token (putting the resulting micromegas_auth::types::AuthContext in the request extensions) and supplies the tool providers; queries are forwarded to FlightSQL with the caller’s token, which stays the enforcement point.
