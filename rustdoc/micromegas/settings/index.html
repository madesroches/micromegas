Module settings 

Source
Expand description

DB-backed deployment settings.

The settings table (data-lake migration v12) is a generic key/value store. SETTINGS is the registry of keys a service understands: it drives the admin page and holds the single validation rule shared by the write path and the loader. A key with no row is “unset”, and the consuming service falls back to the env var, then to the built-in default.

Each service caches the whole table through SnapshotSource, the same cache the audience-grant and group stores use, and reads typed values through SettingsSource.
