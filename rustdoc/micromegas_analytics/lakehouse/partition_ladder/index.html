Expand description

Aligned bucket ladder and planner sizing JIT partitions from the query range Aligned bucket ladder (minute, 5 min, hour, 6 h, day) used to size JIT partitions from the query range, and the planner that turns per-minute block counts into the buckets to materialize.

Every rung divides the next one and duration_trunc aligns to the Unix epoch, so buckets of different rungs nest and never straddle each other.

plan_dense_buckets
Plans the buckets to materialize over insert_range (rung-aligned) when no per-bucket count is available: every bucket is assumed non-empty and none descends on object count. A closed bucket is emitted at rung; only the open edge descends, down to finest. A bucket that begins at or after insert_range.end is dropped, so the open edge stops at the end of the range instead of planning empty future buckets.
