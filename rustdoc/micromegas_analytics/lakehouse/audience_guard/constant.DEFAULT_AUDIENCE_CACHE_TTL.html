Default freshness bound for AudienceIndex’s cache entries. The only invalidation mechanism: a process’s Postgres row is written once and never updated in place, but a retention-then-re-export cycle can recreate the same process_id (deterministic UUIDv5 for OTLP) under fresh properties, and nothing else ever expires a stale cached answer. Bounds how long a re-derived process’s audience can serve a stale answer.
