Environment variable capping the HTTP telemetry sink’s max level. Read once by TelemetryGuardBuilder::build. Precedence is TelemetryGuardBuilder::with_telemetry_sink_max_level > this variable > the DEFAULT_TELEMETRY_SINK_MAX_LEVEL default. Accepts the same values as LOCAL_SINK_MAX_LEVEL_ENV_VAR; an unparseable value fails build(), even if no telemetry URL ends up configured.
