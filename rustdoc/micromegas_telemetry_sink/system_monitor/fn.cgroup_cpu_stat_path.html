pub fn cgroup_cpu_stat_path(proc_self_cgroup: &str) -> String
Expand description

Resolves this process’s own cgroup cpu.stat from the contents of /proc/self/cgroup. Without a cgroup namespace the root file would report host-wide usage, so the 0::<path> line is followed; the root file is the fallback when there is no v2 line.
