Same default-detection and data pipeline as Option A — only the median encoding differs. A vertical gold tick is drawn over the bar area at the estimated median's x-position, with the numeric value trailing the chart in a fixed-width label (so labels stay aligned column-wide, unlike Option A's overlay which can collide with a tall bar under it). Tick position uses the same client-side linear-interpolation estimate as quantile_from_histogram(). Last row shows the debug view: an ordinary Markdown override on this column with format: "$row.duration_dist" — no dedicated debug feature needed, since a histogram-typed value now formats as its raw struct fields (instead of stringifying uselessly) wherever a markdown template references it.
