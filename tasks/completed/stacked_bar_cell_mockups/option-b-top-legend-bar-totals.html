Stacked Bar — Option B: legend above + totals on bar caps

Legend wraps in a row above the plot so the bars get the full cell width (better for many categories or narrow cells). Absolute view labels only the bar total on each cap — segment values live in the tooltip — which keeps the chart quiet. Percent view falls back to in-segment labels since every total is 100%.
