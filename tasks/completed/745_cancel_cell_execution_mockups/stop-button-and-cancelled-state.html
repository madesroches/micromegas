Cancel a running cell

A running cell's Run button turns into a Stop button (always visible while running, not hover-only). Stopping aborts the whole run: the running cell shows Cancelled and keeps the data it had, cells that had not started stay idle. Hover a header to see its controls; the first notebook below is interactive.
