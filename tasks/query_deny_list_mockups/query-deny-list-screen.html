Deny a Query

Copy sql_hash from the query audit log. Literals are stripped before hashing, so every refresh of the same dashboard shares one fingerprint.
Shown to whoever finds a query failing, and in the rules table — say why, and what has to happen before the rule comes back off.
All fields you fill in must match for a query to be rejected. At least one matcher is required — a rule that would match everything is refused. The rule stands until someone removes it.
