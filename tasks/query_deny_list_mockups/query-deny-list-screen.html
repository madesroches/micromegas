Deny a Query

insert:
A boolean SQL predicate over the match context — user_id, email, service_account, client, agent, entrypoint, session, notebook, cell, client_ip, sql, sql_hash. Supports AND/OR/NOT, =, !=, IN, LIKE, IS NULL, regexp_like(). Reference →
Copy sql_hash from the query audit log: literals are stripped before hashing, so every refresh of the same dashboard shares one fingerprint.
Shown to whoever finds a query failing, and in the rules table — say why, and what has to happen before the rule comes back off.
The rule stands until someone removes it. An expression that references no column at all is refused.
